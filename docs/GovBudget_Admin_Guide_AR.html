1. الأدوار وصلاحيات البرامج

يستخدم النظام ثلاثة أدوار تُطبَّق كصلاحيات أمنية عند تسجيل الدخول.

SYSADMIN ADMIN USER

  • SYSADMIN — مستخدم عام أعلى صلاحية، غير مرتبط بأي جهة.
  • ADMIN — إما مسؤول عام (بدون جهة، يعمل على مستوى النظام) أو مسؤول جهة (محصور في جهة واحدة).
  • USER — مُعِدّ الموازنة المرتبط بجهة/إدارة؛ يستخدم البرامج فقط أثناء إدخال الموازنة.
شكل 1 — شاشة تسجيل الدخول إلى GovBudget.

2. البدء واختيار السياق

  1. سجّل الدخول باسم المستخدم وكلمة المرور.
  2. اختر السياق: السنة المالية، الجهة، الإدارة.
  3. يمكن لـ SYSADMIN/المسؤول العام التبديل بين الجهات؛ بينما مسؤول الجهة محصور بجهته.
شكل 2 — إعداد الموازنة: اختر السنة المالية والجهة ومركز التكلفة (الإدارة).

3. إعداد البيانات المرجعية

  • الجهات — المؤسسات/الهيئات.
  • الإدارات — الوحدات التابعة لكل جهة.
  • الحسابات المحاسبية والبنود — دليل الحسابات وبنود الموازنة.
  • الفئات — إيرادات، رأسمالي، تشغيلي، موارد بشرية.
شكل 3 — غرفة المسؤول (Admin Room): نقطة الدخول للجهات ومراكز التكلفة والمستخدمين والحسابات والبنود والبرامج والأنشطة والمشاريع وسجلات التدقيق.

4. إدارة البرامج (تكليف مقابل مساندة)

نوع البرنامج

  • تكليف (Mandate) — برامج المهمة الأساسية؛ تستقبل التكاليف الموزّعة (النوع الافتراضي).
  • مساندة (Support) — برامج مساندة/تشغيلية؛ يمكن توزيع تكلفتها على أنشطة برامج التكليف. ويمكن منحها تسلسل توزيع (ترتيب التوزيع التنازلي).

لإنشاء أو تعديل برنامج

  1. افتح البرامج واضغط إنشاء (أو عدّل برنامجاً قائماً).
  2. أدخل رمز البرنامج واسمه (الرمز فريد داخل الجهة).
  3. اختر نوع البرنامج: تكليف أو مساندة.
  4. للمساندة، حدّد تسلسل التوزيع اختيارياً (الأقل يُوزَّع أولاً).
  5. فعّل خيار نشط ثم احفظ.
[ صورة الشاشة ]
نموذج إنشاء/تعديل البرنامج — النوع وتسلسل التوزيع
التقاط: نموذج Programs → Create مع إبراز قائمة النوع.
تنبيه النطاقيرى مسؤول الجهة برامج جهته فقط ويعدّلها؛ حقل الجهة مقفل، والوصول لجهة أخرى مرفوض.

5. الأنشطة والمشاريع

تنتمي الأنشطة إلى برنامج وإدارة. في إدخال الموازنة يختار المستخدم برنامجاً ثم نشاطاً مرتبطاً بذلك البرنامج — وهذا ما يجعل التكاليف تتجمّع بشكل صحيح.

التقاط: قائمة الأنشطة مفلترة حسب البرنامج.

6. إدارة المستخدمين

  1. افتح المستخدمين ← إنشاء؛ أدخل اسم مستخدم فريداً وكلمة مرور.
  2. اختر الدور: SYSADMIN ADMIN USER.
  3. عيّن الجهة (والإدارة لمستخدم USER):
    • SYSADMIN: بدون جهة/إدارة.
    • ADMIN: يجب ربطه بجهة.
    • USER: يجب ربطه بجهة أو إدارة.
  4. يمكن لـ SYSADMIN فقط إنشاء/تعديل حسابات SYSADMIN. ومسؤول الجهة يدير مستخدمي جهته فقط.
شكل 4 — نموذج المستخدم: اسم المستخدم، كلمة المرور، الدور (USER / ADMIN)، الجهة، الإدارة وحالة التفعيل.
إلغاء التفعيلحذف المستخدم يُلغي تفعيله للحفاظ على السجل التاريخي.

7. محرك توزيع التكاليف

لمستخدمي SYSADMIN / المسؤول العام ADMIN فقط. يعيد توزيع تكاليف برامج المساندة على أنشطة التكليف — إضافي وقابل للتدقيق، ولا يعدّل بنود الموازنة الأصلية.

السلوك الافتراضي

تبقى كل تكلفة على نشاط البرنامج الذي أُدخِلت فيه (أساس مباشر). ولا يُطبَّق أي توزيع حتى يتم اعتماد عملية تشغيل.

تشغيل عملية توزيع

  1. افتح توزيع التكاليف، اختر السنة المالية (والجهة).
  2. تأكّد من تصنيف البرامج (برامج المساندة وتسلسلها).
  3. عرّف المحرّكات (مثل عدد الموظفين) وأدخل القيم.
  4. أنشئ قواعد تربط كل برنامج مساندة بأنشطة التكليف المستهدفة عبر محرّك.
  5. شغّل التوزيع التنازلي وراجع الحركات.
  6. اعتمِد العملية؛ عندها تعرض التقارير على أساس الإجمالي آخر عملية معتمدة.
[ صورة الشاشة ]
توزيع التكاليف — القواعد والتصنيف
التقاط: شاشة Allocation → Index.
ضمان التوازن الصفريكل قيد يضيف للنشاط المستهدف (موزّع داخل) ويخصم من البرنامج المصدر (موزّع خارج) بنفس المبلغ، فتُحفظ التكلفة الإجمالية.

8. حزمة المراجعة الإدارية

لمستخدمي SYSADMIN / المسؤول العام ADMIN فقط. تقارير للقراءة فقط:

  • هيكل التكلفة وانضباط الإنفاق الرأسمالي.
  • تكلفة القوى العاملة لكل موظف.
  • تكلفة البرنامج (مباشر + موزّع).
  • بطاقة مؤشرات الأداء وتفاصيلها، سلّم النضج، تكلفة وحدة النشاط.
  • تصدير Excel لكل الأوراق.

9. التقديم والاعتمادات

  • يقدّم المستخدمون الموازنة لكل سنة/جهة/إدارة/فئة.
  • بعد التقديم تصبح مقفلة حتى تُعاد.
  • يراجع المسؤولون ويعتمدون أو يعيدون مع ملاحظات.

10. سجلات التدقيق والرسائل الداخلية

  • سجلات التدقيق تسجّل الإجراءات المهمة (للمسؤول فقط، محصورة بالجهة).
  • الرسائل الداخلية تتيح للمستخدمين رفع الطلبات ورد المسؤولين عليها.
