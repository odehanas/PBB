Part A — Administrator Guide

A1. Roles & Program Authority

GovBudget uses three roles, stored on each user account and applied as security claims when the user signs in.

SYSADMIN ADMIN USER

  • SYSADMIN — global super-user. Not tied to any entity; sees and manages every entity's data, the cost allocation engine, and the management review pack.
  • ADMIN — exists in two practical forms:
    • Global ADMIN (no entity assigned) — behaves as a system-level administrator.
    • Entity ADMIN (assigned to one entity) — restricted to that entity's programs, users and data.
  • USER — a budget preparer linked to an entity or department. Cannot open the administration screens; uses programs only while entering a budget.

A2. Getting Started & Context

  1. Sign in with your username and password.
  2. Choose the working Context: Budget Year, Entity, and Department. The system holds this selection for your session.
  3. SYSADMIN / Global ADMIN can switch to any entity; an Entity ADMIN or USER is limited to their assigned scope.

A3. Reference Data Setup

Set up reference data before programs and budgets are entered:

  • Entities — the organisations/authorities.
  • Departments — units under each entity.
  • GL Accounts & Items — the chart of accounts and budget line items.
  • Categories — Revenue, CAPEX, OPEX, HR.

A4. Managing Programs (Mandate vs Support)

Programs group the work of an entity. Each program now carries a type that drives cost allocation.

Program type

  • Mandate — core mission programs. These ultimately receive allocated overhead. (Default type.)
  • Support — overhead/enabling programs whose cost can be pushed down onto mandate activities. A Support program may be given an Allocation Sequence that controls the step-down order.

To create or edit a program

  1. Open Programs from the admin menu.
  2. Click Create (or edit an existing program).
  3. Enter the Program Code and Name. Codes must be unique within the entity.
  4. Choose the Program Type: Mandate or Support.
  5. For Support programs, optionally set the Allocation Sequence (lower numbers allocate first). For Mandate programs the sequence is not used.
  6. Set Active so the program appears in budget entry, then save.
Scope reminder An Entity ADMIN only sees and can edit programs for their own entity; the entity field is locked to their entity. Attempting to reach another entity's program is denied.

A5. Activities & Projects

Activities belong to a program and to a department. When a budget line is entered, the user picks a program and then an activity linked to that program. This linkage is what makes costs roll up to the right program.

  • Keep activities mapped to the correct program so direct costs land where expected.
  • Projects are used for CAPEX/initiative-style budgeting and are selected per department.

A6. User Administration

  1. Open Users from the admin menu.
  2. Click Create, enter a unique username and password.
  3. Choose the role: SYSADMIN ADMIN USER.
  4. Assign the entity (and department for a USER). Rules:
    • A SYSADMIN has no entity/department.
    • An ADMIN must be linked to an entity.
    • A USER must be linked to an entity or department.
  5. Only a SYSADMIN can create or edit other SYSADMIN accounts. An Entity ADMIN can only manage users within their own entity.
DeactivationDeleting a user actually deactivates the account (sets it inactive) so history is preserved.

A7. Cost Allocation Engine

SYSADMIN / Global ADMIN only.

The allocation engine reallocates Support program costs onto Mandate program activities. It is additive and auditable — it never edits the original budget lines.

Default behaviour

By default, every cost stays on the activity of the program where it was entered (the Direct cost basis). No allocation is applied until you run one.

Running an allocation

  1. Open Cost Allocation and select the Budget Year (and entity if scoping).
  2. Confirm program classification — which programs are Support and their sequence.
  3. Define allocation drivers (e.g. headcount, floor area) and enter driver values.
  4. Create allocation rules that map each Support program to its target mandate activities using a driver.
  5. Run the step-down allocation. Review the generated transactions.
  6. Post the run when satisfied. Reports using the Total cost basis will then overlay the latest posted run.
Net-zero guaranteeEach posting credits the target activity (allocated-in) and debits the source program (allocated-out) by the same amount, so total cost is preserved.

A8. Management Review Pack

SYSADMIN / Global ADMIN only. A read-only reporting pack:

  • Cost structure & capex discipline.
  • Manpower cost-per-FTE.
  • Programme cost (Direct + Allocated).
  • KPI scorecard & detail, maturity ladder, activity unit cost.
  • Excel export of all sheets.

A9. Submissions & Approvals

  • Users submit a budget per Year / Entity / Department / Category.
  • Once submitted, the budget is locked and editing is disabled until it is returned.
  • Admins review submissions and approve or return them with comments.

A10. Audit Logs & Internal Messages

  • Audit logs record key actions (admin-only, scoped by entity).
  • Internal messages let users raise requests and admins respond/review.

Part B — Regular User Guide

B1. Logging In & Choosing Your Context

  1. Sign in with the username and password provided by your administrator.
  2. Select your Context: Budget Year, Entity and Department. You can only see the entity/department assigned to you.
  3. This selection stays active for your session and drives every screen.

B2. Understanding Programs & Activities

A program is a block of work in your entity; an activity is a specific piece of work inside a program. When you budget, you always choose a program first, then an activity that belongs to it.

  • Mandate programs are your core mission work.
  • Support programs are shared/overhead work. You budget them the same way; administrators may later spread their cost onto mandate activities.
What you seeThe program list shows only the active programs of your own entity. If a program is missing, ask your administrator to add or activate it.

B3. Entering a Budget

  1. Open Budget Entry and pick the category: Revenue, CAPEX, OPEX or HR.
  2. Select the Program, then the Activity (the list filters to that program).
  3. Choose the line Item (account) and enter amounts.
  4. Spread the amount across months — equally or by entering values per month.
  5. For CAPEX you can attach a supporting document (up to 5 MB) and set depreciation details.
  6. Save the line. It appears in the recent-lines list for the current context.

B4. Submitting for Approval

  1. When your lines are complete, submit the budget for your context.
  2. After submission the budget is locked and cannot be edited.
  3. If changes are needed, ask your administrator to return it; once returned you can edit and resubmit.

B5. Reports Available to You

You can view reports for your own scope (such as income statement and budget summaries). Cross-entity tools — Cost Allocation and the Management Review pack — are reserved for administrators.

B6. FAQ & Troubleshooting

I can't find a program in the dropdown.

It may be inactive or belong to a different entity. Contact your administrator.

The Save button is disabled / I get a "locked" message.

The budget has been submitted. Ask your administrator to return it for editing.

I don't see the admin menus.

Those screens are limited to administrators. Your role is USER.
