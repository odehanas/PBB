How the What-If simulator works and its effect on submission versions · كيف يعمل محرّك «ماذا لو» وأثره على إصدارات الاعتماد
English (left column) العربية (العمود الأيمن)

1. What What-If is

What-If is a read-only simulator. It lets you preview how your budget would look under different assumptions — without changing any real budget data.

  • You create named scenarios for a specific Year + Entity + Department.
  • Each scenario applies rate assumptions to your existing budget lines and shows the projected new amounts and the difference (delta).
  • It is purely analytical: nothing you do here edits, submits, approves, or locks a budget.

١. ما هو «ماذا لو»

«ماذا لو» أداة محاكاة للقراءة فقط. تتيح لك معاينة شكل الموازنة وفق افتراضات مختلفة — دون تغيير أي بيانات فعلية للموازنة.

  • تنشئ سيناريوهات مُسمّاة لسنة + جهة + إدارة محددة.
  • يطبّق كل سيناريو نسب افتراضات على بنود موازنتك الحالية ويعرض المبالغ الجديدة المتوقعة والفرق (الانحراف).
  • الأداة تحليلية بحتة: لا شيء هنا يعدّل أو يُرسل أو يعتمد أو يقفل الموازنة.

2. What you can set

Each scenario has two rate assumptions:

  • Cost Inflation Rate (%) — applied to cost lines (everything that is not revenue).
  • Revenue Growth Rate (%) — applied to revenue lines.

Per-project overrides

Optionally, you can override either rate per project. If a budget line belongs to a project that has an override, that project's rate is used instead of the scenario default.

٢. ما الذي يمكنك ضبطه

لكل سيناريو افتراضان للنسبة:

  • نسبة تضخّم التكلفة (%) — تُطبّق على بنود التكلفة (كل ما ليس إيراداً).
  • نسبة نمو الإيراد (%) — تُطبّق على بنود الإيرادات.

تجاوزات على مستوى المشروع

اختيارياً، يمكنك تجاوز أي من النسبتين لكل مشروع. فإذا كان البند تابعاً لمشروع له قيمة تجاوز، تُستخدم نسبة ذلك المشروع بدلاً من القيمة الافتراضية للسيناريو.

3. How the math works

For every budget line the system picks the right rate (project override if any, otherwise the scenario default; revenue rate for revenue lines, cost rate otherwise) and computes:

multiplier = 1 + rate / 100 new unit price = round(unit price × multiplier, 2) new amount = round(quantity × new unit price, 2) delta = new amount − base amount

Totals are summed across all lines: base total, scenario total, and total delta.

٣. كيف تُحتسب الأرقام

لكل بند يختار النظام النسبة المناسبة (تجاوز المشروع إن وُجد، وإلا القيمة الافتراضية للسيناريو؛ نسبة الإيراد لبنود الإيراد، ونسبة التكلفة لغيرها) ثم يحسب:

multiplier = 1 + rate / 100 new unit price = round(unit price × multiplier, 2) new amount = round(quantity × new unit price, 2) delta = new amount − base amount

تُجمَع الإجماليات عبر كل البنود: الإجمالي الأساسي، إجمالي السيناريو، وإجمالي الفرق.

5. Scope & the active scenario

  • Scenarios are tied to your selected context (Year / Entity / Department). You must pick a context first.
  • You can Activate one scenario at a time; the active scenario is remembered for your session.
  • Clear removes the active scenario so you see base figures again.
  • While a scenario is active, scenario-adjusted figures can be viewed in the analysis; the base budget remains untouched.

٥. النطاق والسيناريو النشِط

  • ترتبط السيناريوهات بـالسياق المختار (السنة / الجهة / الإدارة). يجب اختيار السياق أولاً.
  • يمكنك تفعيل سيناريو واحد في كل مرة؛ ويُحفظ السيناريو النشِط طوال جلستك.
  • المسح (Clear) يزيل السيناريو النشِط لتعود لرؤية الأرقام الأساسية.
  • أثناء تفعيل سيناريو، يمكن عرض الأرقام المعدّلة في التحليل؛ وتبقى الموازنة الأساسية دون مساس.

6. Impact on submission versions

None — by design.

What-If reads your budget lines but never writes to them. It only stores the scenario's rates. Therefore it:

  • does not create or change submission versions;
  • does not change any status (Draft / Submitted / Approved …);
  • does not lock or unlock anything.
Key point You can run What-If even on a budget that is already Submitted or Approved — because it only simulates and never edits. The numbers you see are a preview, not a saved change.

٦. الأثر على إصدارات الاعتماد

لا يوجد — بحكم التصميم.

«ماذا لو» يقرأ بنود الموازنة لكنه لا يكتب فيها أبداً. وهو يخزّن نسب السيناريو فقط. ولذلك فهو:

  • لا ينشئ أو يغيّر إصدارات الاعتماد؛
  • لا يغيّر أي حالة (مسودة / مُرسَل / معتمد …)؛
  • لا يقفل أو يلغي قفل أي شيء.
نقطة جوهرية يمكنك تشغيل «ماذا لو» حتى على موازنة مُرسَلة أو معتمدة — لأنه يحاكي فقط ولا يعدّل. فالأرقام التي تراها معاينة وليست تغييراً محفوظاً.

7. Turning a scenario into a real change

If you decide a scenario's outcome is what you want, you apply it manually through the normal budget process:

  1. Open Budget Entry while the category is in Draft (or have an admin Return it for revision first).
  2. Edit the actual budget lines to the desired figures.
  3. Submit — this is what creates / advances a real submission version.

What-If informs the decision; the submission workflow records it.

٧. تحويل السيناريو إلى تغيير فعلي

إذا قررت أن نتيجة السيناريو هي ما تريده، فإنك تطبّقه يدوياً عبر مسار الموازنة المعتاد:

  1. افتح إدخال الموازنة والفئة بحالة مسودة (أو اطلب من المسؤول إرجاعها للتعديل أولاً).
  2. عدّل بنود الموازنة الفعلية إلى الأرقام المطلوبة.
  3. أرسِل — وهذا ما ينشئ/يقدّم إصدار اعتماد حقيقياً.

«ماذا لو» يدعم القرار، ومسار الاعتماد هو من يسجّله.

8. Quick FAQ

QuestionAnswer
Does What-If change my budget?No. It only simulates.
Does it create a new version?No. Versions come only from Submit / Return.
Can I use it after submitting?Yes. It is read-only, so the lock doesn't matter.
How do project overrides work?They replace the scenario default rate for lines on that project.
Many scenarios at once?You keep many, but only one is active per session.
