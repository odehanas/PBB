1. Roles & Program Authority

GovBudget uses three roles, applied as security claims at login.

SYSADMIN ADMIN USER

  • SYSADMIN — global super-user, not tied to any entity.
  • ADMIN — Global ADMIN (no entity, acts system-wide) or Entity ADMIN (restricted to one entity).
  • USER — budget preparer linked to an entity/department; uses programs only in budget entry.

4. Managing Programs (Mandate vs Support)

Program type

  • Mandate — core mission programs; receive allocated overhead (default type).
  • Support — overhead programs; cost can be pushed onto mandate activities. May be given an Allocation Sequence (step-down order).

To create or edit a program

  1. Open Programs and click Create (or edit an existing one).
  2. Enter Program Code and Name (code unique per entity).
  3. Choose Program Type: Mandate or Support.
  4. For Support, optionally set the Allocation Sequence (lower allocates first).
  5. Set Active and save.

6. User Administration

  1. Open Users → Create; enter a unique username and password.
  2. Choose role: SYSADMIN ADMIN USER.
  3. Assign entity (and department for a USER):
    • SYSADMIN: no entity/department.
    • ADMIN: must have an entity.
    • USER: must have an entity or department.
  4. Only a SYSADMIN can create/edit SYSADMIN accounts. An Entity ADMIN manages only their own entity's users.
Figure 4 — User form: username, password, Role (USER / ADMIN), Entity, Department and Active flag.
DeactivationDeleting a user deactivates the account so history is preserved.

7. Cost Allocation Engine

SYSADMIN / Global ADMIN only. Reallocates Support program costs onto Mandate activities — additive and auditable; never edits original budget lines.

Default behaviour

Every cost stays on the activity of the program where it was entered (Direct basis). No allocation applies until a run is posted.

Running an allocation

  1. Open Cost Allocation, select the Budget Year (and entity).
  2. Confirm program classification (Support programs & sequence).
  3. Define drivers (e.g. headcount) and enter values.
  4. Create rules mapping each Support program to target mandate activities via a driver.
  5. Run the step-down allocation; review transactions.
  6. Post the run. Reports on the Total basis then overlay the latest posted run.

Net-zero guaranteeEach posting credits the target activity (allocated-in) and debits the source program (allocated-out) by the same amount, preserving total cost.

8. Management Review Pack

SYSADMIN / Global ADMIN only. Read-only reporting:

  • Cost structure & capex discipline.
  • Manpower cost-per-FTE.
  • Programme cost (Direct + Allocated).
  • KPI scorecard & detail, maturity ladder, activity unit cost.
  • Excel export of all sheets.

9. Submissions & Approvals

  • Users submit a budget per Year / Entity / Department / Category.
  • After submission it is locked until returned.
  • Admins review and approve or return with comments.

10. Audit Logs & Internal Messages

  • Audit logs record key actions (admin-only, entity-scoped).
  • Internal messages let users raise requests and admins respond.
